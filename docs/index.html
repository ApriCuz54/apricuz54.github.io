Side project since Sep 2026. The repo is not public yet.

Research

Cost-Aware Fine-Tuning for Efficient LLM Adaptation

First author, IEEE AIMLSys EDGE-X 2025. BITS Pilani.

A system-level study of parameter-efficient fine-tuning and hyperparameter search across CPU, T4, L4 and A100 hardware. Freezing all but the top two layers matched full fine-tuning accuracy while training about 10% of the parameters, and cut CPU training time by up to 86%.

Agent Civilizations: LLM agents in multi-agent games

Independent research, in progress

A reproducible, cost-logged harness covering a pricing duopoly, the iterated prisoner's dilemma, an Axelrod-style strategy panel, reputation systems and a commons: 14 experiments and 15,348 model calls so far. Single instructions can reliably tip agents toward collusive pricing or defection, while prosocial phrasing did nothing measurable above an already cooperative baseline. A lifetime reputation score gets gamed by agents that build trust and then betray; a recency window closes that gap, and forged histories reopen it.
